## ⚡ What is Pinganator 7000?

**Pinganator 7000** is an Android application built around one simple idea:

> **Send ping. Get answer. Don't overthink it.**

Whether you're checking a device on your local network, testing connectivity, or just wondering whether some host is still alive — Pinganator is here to do the job.

No enterprise dashboards.
No 47 configuration screens.
No unnecessary complexity.

Just pinging things.
Like it's the year 7000.

## 🚀 Getting started

### Clone the repository

```bash
git clone https://github.com/kirill050/pinganator7000.git
cd pinganator7000
```

### Open in Android Studio

1. Open **Android Studio**
2. Select **Open**
3. Choose the cloned `pinganator7000` directory
4. Wait for Gradle sync to finish
5. Connect an Android device or start an emulator
6. Press **Run ▶**

And congratulations.

You now possess the power of the **Pinganator 7000**.

---

## 🔨 Build from command line

On Linux / macOS:

```bash
./gradlew assembleDebug
```

On Windows:

```powershell
gradlew.bat assembleDebug
```

The debug APK will normally appear under:

```text
app/build/outputs/apk/debug/
```
